# Bounded attention with reference-aligned arithmetic

Qwen3 uses FP32 QK, softmax and PV computation over its BF16/F16 projections and paged KV cache. CUDA RMS normalization preserves the reference reduction order for widths 128 and 1024, and packed QKV/gate-up weights are executed as independent projections. The original fused projection and attention arithmetic failed the frozen numerical budgets; matching the reference's materialization and batch geometry removed every logit discrepancy in the 28-case development prototype without changing inputs, reference outputs or thresholds.

`PreparedAttention` selects a rectangular query layout when both the existing token budget and attention workspace allow it. It owns real-row indices, cumulative lengths and physical block tables once per step. Model layers pad hidden states and positions consistently, write only real K/V rows, and restore packed output rows before returning to the engine. Larger or uneven work uses packed sequences, query chunks and, when needed, individual query heads under the same FP32 arithmetic. CUDA kernels derive causal masks and paged gathers from prepared device metadata; no layer builds a host mask or uploads block indices.

The workspace allowance uses half of the headroom remaining after KV allocation; the rest is reserved for model activations and library workspaces. Layout estimates include attention casts, expansion, scores and output assembly, including retained members and final batch concatenation. Paged gather reads only logical visible keys even when the scheduler has reserved future blocks. A step that cannot fit the smallest planned layout fails before metadata upload. This is a correctness-oriented trade-off: greater compute and temporary-memory cost must be measured by the release performance gate. It is not a claim of production numerical or performance acceptance, and packed fallback shapes still require their own evidence.

# Retain observed confirmation and freeze a new independent cohort

The first independent confirmation run stopped at 32/617 owners when
confirmation-batch-medium exceeded the unchanged mean/peak KL budgets. That
input informed the call-layout-v2 repair. Its original FAIL remains a FAIL;
passing it with new code supplies regression evidence and cannot restore its
unseen status. We propose retaining all 617 owners and adding a fresh 130-owner
confirmation cohort, for 747 mandatory owners.

Registry schema3 records confirmation cohorts separately from case splits.
The first cohort becomes mandatory regression evidence without changing any
original case object, split, input, option, source literal or owner record.
The second cohort is independently prepared using only the pinned CPU tokenizer
and new coastal-station literals. Its 13 execution groups, 19 numerical cases,
75 base prediction rows and 11 behavior checks preserve the existing coverage
geometry. No model output has been consulted. Input-only independence checks
reject any reachable prediction-history overlap with all previous cases,
including the first confirmation cohort and public/setup calls.

The registry requires complete, disjoint cohort membership and exactly one
independent cohort with actual prediction history. Error-only public calls cannot
stand in for new model evidence. A behavior cannot borrow another cohort's execution group.
The evaluator still requires every old and new owner and includes the frozen
cohort roles in its evidence report. A passing new cohort never waives an old
failure, missing owner or invalid replay/control.

This is a proposed Definition Checkpoint. The numerical policy deliberately
continues to bind the previous registry, sealing numerical and public-behavior
confirmation entrypoints. Complete the new source's CPU gates, calibration,
fault evidence and independent reviews before seeking approval of this concrete
list and its bindings. Existing FP32 reference arithmetic and every model/operator
budget stay unchanged. Approval of an earlier cohort is not approval of this one;
this proposal itself grants neither new holdout output access nor publication.

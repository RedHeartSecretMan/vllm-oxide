# v0.2.0 correctness-first release scope

Earlier ADRs projected runtime TP/NCCL, multi-candidate sampling, additional
task traits, and CUDA Graphs into v0.2. The approved v0.2.0 specification in
GitHub Issue #28 instead fixes the release boundary at trustworthy,
repeatable, single-GPU Qwen3 offline causal generation, centered on
`LLM::generate` and an internal `StepPlan` / `StepResult` seam.

**Decision**: v0.2.0 completes correctness, resource-safe initialization,
device-oriented hot paths, fail-closed golden validation, and release closure
before expanding product scope. Runtime TP/NCCL, additional task families,
multi-candidate sampling, CUDA Graphs, serving, quantization, LoRA, and
speculative decoding are deferred beyond v0.2.0.

**Supersedes**: the release-placement statements for expansion capabilities in
ADR-0001 and ADR-0004, the v0.1 `EngineCore::step()` coordination contract in
ADR-0004 for v0.2.0 operation, and ADR-0005's legacy global-tolerance and
skip-based acceptance policy. Existing architectural seams remain accepted
unless this ADR explicitly replaces their coordination or release semantics.

**Status**: accepted

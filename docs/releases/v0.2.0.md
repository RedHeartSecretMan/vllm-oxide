# v0.2.0 — 单 GPU Qwen3 离线推理

发布日期：2026-10-13。完整精度验收、实际 CUDA API/CLI 验证和性能基线已经通过，发布集成 PR 的 CPU CI 全绿。验证来源、范围和哈希见[验收摘要](goldens-v0.2.md)。

## 支持范围

- 单 GPU、Qwen3-0.6B、BF16、同步离线 `LLM::generate`。
- 持续批处理、分页 KV、prefix cache、等待准入和抢占重算。
- 公共 Rust 接口为 `LLM`、`EngineOptions`、`Prompt`、`SamplingParams`、`RequestOutput`、`Source`；推理通过 `LLM::new` 和 `LLM::generate` 完成。
- Rust 1.94 或更新版本；实际模型推理需要 `--features cuda`，从源码构建需要包含 `nvcc` 的 CUDA Toolkit。
- 发布实测环境为 Linux/WSL2、RTX 4080（SM 8.9）、驱动 595.71、CUDA Toolkit 13.2.51。固定模型为 `Qwen/Qwen3-0.6B@7e4ae267688d671ddfca3122e4528ee980cf3234`。
- 不包含服务 API、多 GPU/TP/NCCL、其他模型族、量化、LoRA、speculative decoding 或 CUDA Graphs。

## 修复与验证

独立 QKV/MLP 投影、明确的 FP32 GEMM 中间归约、参考顺序 RMSNorm、有界 FP32 因果 attention 和 `call-layout-v2` 修复了已定位的精度与批次布局问题。调度、缓存和公开生成接口保留完整的请求身份、token 历史及采样策略。

- **精度**：原测量来源 `33e0e27` 与独立评估来源 `ba5eb79` 的完整验收为 PASS，覆盖 747 个采集项、231 个执行组、104 项数值比较、44 项行为检查和 7 项算子检查。原 KL 和参考选择损失预算保持不变。
- **功能**：发布实现 `3b1cdceb` 的生产 CUDA 构建、真实 warmup、100 次重复 `LLM::generate`、3 个混合请求和 Quick Start CLI 均通过；107 个请求 ID 唯一，CLI 输出为 `Paris.`。
- **性能**：已批准 producer `e785a21` 的两种固定工作负载均完成一次丢弃的 warmup 和三次测量。单请求 decode 中位数为 29.7601 token/s，四请求 batch 为 115.8207 token/s；六次测量的原始时序、输出、统计与显存采样均通过复算。
- **CPU CI**：GitHub 的 Rust 1.94/stable、Python CPU 适配器与质量检查、依赖审计通过。普通 CI 无需 GPU；模型数值、CUDA 功能和性能使用本地 GPU 验证。

性能记录是该固定环境的基线，不是跨硬件最低吞吐保证，也不表示与 vLLM 性能相同。

# v0.2.0-rc.1 — experimental source prerelease

这是用于试用与反馈的源码预发布，**不是精度达标或生产就绪声明**。用户已选择先交付 RC1；正式 v0.2.0 的精度、性能和发布门禁保持不变。RC1 不关闭 #45、#46、#47，不生成数值 PASS 标记，也不发布 `goldens-v0.2`。

## 范围

- 单 GPU、Qwen3-0.6B、BF16、离线同步 `LLM::generate`。
- 包含当前持续批处理、分页 KV、prefix cache、等待准入和抢占重算实现，以及已验证的有界资源监督工具。
- RC 收尾仅调整 workspace 版本、CLI `cuda` feature 转发和发布文档；不修改推理算子、权重、测试输入或数值预算。
- 不包含服务 API、多 GPU/TP/NCCL、其他模型族、量化、LoRA、speculative decoding 或 CUDA Graphs。

## 试用

使用 Linux CUDA 环境与 SM89+ NVIDIA GPU；记录的验证环境为 WSL2 / RTX 4080。请使用 Rust 1.94.0，**未验证历史 manifest 声明的 Rust 1.75 下限**。需要可用 CUDA 工具链及模型文件；没有附带跨平台预编译二进制或模型权重。

```bash
git clone --branch v0.2.0-rc.1 --depth 1 https://github.com/RedHeartSecretMan/vllm-oxide.git
cd vllm-oxide
cargo run --locked --release -p vllm_oxide_cli --features cuda -- \
    --model /path/to/Qwen3-0.6B --max-tokens 2 "The capital of France is"
```

模型目录应为上面的固定 revision。CLI 也接受 Hub repo ID，但该形式没有 revision 参数，不能作为固定 revision 的验证命令。CPU-only 构建仅用于开发与测试，不执行模型推理。

```bash
cargo test --locked --workspace --features internal-golden
```

RC 发布附件中的验证报告记录准确 RC 提交、CPU 检查和短时 CUDA CLI smoke 结果；smoke 只验证基本启动/生成，不替代正式精度、完整性能或完整 #46 门禁。此前测量的数值 FAIL 持续有效。

## 本版重点

- 通过同步、单 GPU `LLM::generate` 提供 Qwen3-0.6B/BF16 推理。
- 包含持续批处理、分页 KV、prefix cache、等待准入、chunked prefill 和抢占重算。
- 加入有界监督及验证工具，保留原数值预算和测量身份。
- 准备预发布版本并转发 CLI 的 `cuda` feature；RC 收尾未修改推理算子、权重或验证输入。

## 升级与兼容性

记录的验证环境为 **RTX 4080/WSL2、Rust 1.94.0**。推理需要 Linux（包括 WSL2）、SM 8.9+ NVIDIA GPU、兼容 CUDA 驱动、CUDA Toolkit 与模型文件。历史 `Cargo.toml` 声明的 Rust 1.75 下限**未验证**；复现 RC 结果请使用记录的 Rust 1.94.0 环境。

Git tag 为 **`v0.2.0.rc.1`**，Cargo 包版本为 `0.2.0-rc.1`；历史拼写保持不变。需要受支持的 API 与当前环境要求时，请升级到 v0.2.0 并参考[迁移指南](../migration-v0.2.0.md)。

## 获取源码

```bash
git clone --branch v0.2.0.rc.1 --depth 1 https://github.com/RedHeartSecretMan/vllm-oxide.git
cd vllm-oxide
cargo run --locked --release -p vllm_oxide_cli --features cuda -- \
    --model /path/to/Qwen3-0.6B --max-tokens 2 "The capital of France is"
```

模型目录须包含 `Qwen/Qwen3-0.6B@7e4ae267688d671ddfca3122e4528ee980cf3234`。CLI 也接受 Hub repo ID，但该形式没有 revision 参数，不能固定受测 checkpoint。CPU-only 构建仅用于开发与测试，不执行模型推理。

## 已知限制

历史预发布有 18 项数值失败，不提供生产级精度保证。完整性能与声明的 Rust 下限在发布时尚未验证。这些限制属于已被 v0.2.0 取代的 RC1。

本版不包含服务/异步/流式 API、多 GPU/TP/NCCL、其他模型族、量化、LoRA、speculative decoding 或 CUDA Graphs。

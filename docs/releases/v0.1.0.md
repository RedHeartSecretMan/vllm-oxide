# v0.1.0 — 实验性 Qwen3 离线推理

**发布日期：2026-07-26 · 状态：历史实验版本 · [English](v0.1.0.en.md)**

v0.1.0 首次提供 Rust/CUDA 单 GPU Qwen3 离线引擎及 Transformers、vLLM 对照夹具。**新用户请使用 [v0.2.0](https://github.com/RedHeartSecretMan/vllm-oxide/releases/tag/v0.2.0)。** 这个保留的历史快照存在已知精度失败，用于历史对照。

| 版本 | 原始实现提交 | 分发方式 |
|---|---|---|
| [`v0.1.0`](https://github.com/RedHeartSecretMan/vllm-oxide/releases/tag/v0.1.0) | [`5203749`](https://github.com/RedHeartSecretMan/vllm-oxide/commit/52037493b38c2d01c4c07a98d2d8f22ca68f2509) | 源码压缩包、夹具压缩包与清单 |

源码归档现已包含基于原实现的文档维护后续提交，推理与验证工具源码保持不变；这次修订不是新的 GPU 测量。原始实现、文档维护快照和原标签备份见[文档维护记录](../version-doc-update.md)。

## 本版重点

- 引入同步 `LLM::new` / `LLM::generate`、每条 prompt 的采样策略及轻量离线 CLI。
- 实现单 GPU Qwen3 生成的持续批处理、分页 KV 缓存、前缀缓存和抢占重算。
- 提供 greedy、top-k、top-p 采样，以及 repetition、presence、frequency penalties。
- 附带 Transformers/vLLM 对照夹具，记录模型、运行时来源和各夹具校验值。

## 升级与兼容性

记录的验证环境为 **Qwen3-0.6B/BF16、RTX 4080/WSL2**。推理需要 Linux（包括 WSL2）、SM 8.9+ NVIDIA GPU、兼容 CUDA 驱动、CUDA Toolkit 与本地模型文件。没有提供预编译二进制或模型权重。

标签中的 `Cargo.toml` 声明 Rust 1.75；后续 Rust 1.94/stable CI 矩阵没有为这个历史下限建立验证结论。当前 v0.2.0 的验证结果与 API 保证不适用于本快照。[迁移指南](../migration-v0.2.0.md)说明升级到 v0.2.0 的破坏性变化，包括收窄公共 API 和 `seq_id` → `request_id`。

## 获取源码

```bash
git clone --branch v0.1.0 --depth 1 https://github.com/RedHeartSecretMan/vllm-oxide.git
cd vllm-oxide
```

该命令选择历史实现及其文档维护更新。需要当前支持的构建及生成流程时，请改用 v0.2.0 和[使用指南](../getting-started.md)。

## 验证与性能

原始验证**未全部通过**：

| 记录项目 | 历史结果 |
|---|---|
| 夹具覆盖 | 28 组提示词 × 两个对照实现，共 56 份夹具 |
| Logits 覆盖 | 8 组保存完整 logits，20 组保存 top-5 |
| 完整输出 token 一致性 | 8 组中 4 组通过，4 组存在差异 |
| Logits 绝对容差 | `66.46875` |
| 回归排除位置 | 6 个回归用例包含跳过位置 |

这些结果不满足更严格的 v0.2.0 精度契约。本版本没有声明通过验证的发布性能基线。

## 已知限制

历史数值失败和跳过位置保持原状，本版本不提供生产级精度保证。引擎同步、离线，不提供服务/异步/流式 API 或受支持的多 GPU/TP/NCCL 推理。其他模型族、量化、LoRA、speculative decoding 和 CUDA Graphs 不在本版范围内。

# v0.2.0 开发用例精度诊断（2026-10-09）

当前仍不能宣告 #45 通过。这份记录保留开发用例 `canonical_03` 的失败与定位结果，
不是完整验收、预算变更或 golden 发布依据。下表四项完整用例比较使用原始 fixed-prefix
输入、64 个预测位置和原始 Transformers reference。短前缀和修改 reference 算子或输入
的反事实实验仅用于定位，没有替代这些完整比较的 reference。

## 固定范围

- 模型：`Qwen/Qwen3-0.6B@7e4ae267688d671ddfca3122e4528ee980cf3234`。
- GPU：RTX 4080；驱动 595.71；CUDA toolkit 13.2.51。
- Reference：Transformers 4.57.6 / Torch 2.10.0，BF16，SDPA MATH。
- Baseline：vLLM 0.18.1，BF16，FlashAttention 2；实际 worker 记录确认全部 28 层后端。
- 原始候选：`33d5bf583129178882d0950df05d6cffd7e42128`。
  加入只读 trace 的 `c3207407db5b518b9dde98f9cee75084ef485aab` 重现相同 logits。
- 所有 GPU 采集在独立受监督进程中串行运行；诊断结果均为 `accepting=false`。

## 完整用例结果

数值单位为 nats；表中展示值经过舍入，判定使用未舍入结果。
现有绝对上限为 mean KL `0.002`、peak KL `0.005`。
未舍入指标、候选源码身份和 capture 摘要见
[诊断摘要](canonical03-development-summary.json)；摘要不替代原始 capture。

| 实现 | mean KL | peak KL | 绝对条件 |
| --- | ---: | ---: | --- |
| vLLM baseline | 0.0011290781 | 0.0074724415 | FAIL |
| 原始 Rust 候选 | 0.0012414170 | 0.0179691794 | FAIL |
| 本地 FP32 attention 原型 | 0.0009683481 | 0.0050533445 | FAIL |
| 本地 FP32 attention + FP32 LM head 原型 | 0.0008587455 | 0.0058905935 | FAIL |

原始候选相对 baseline 的 paired mean excess 为 `0.0001123389886707997`，
低于 `0.001` 上限；choice loss 峰值为 `0.125`，低于 `ln(1.25)`。
这些条件通过不能抵消绝对 peak KL 失败。Baseline 自身失败同样不能提高候选上限，
也不能证明现有预算不可能满足。

FP32 attention 原型提交为 `b6bab00fe14f42ee67e0436980eed5a46ef1ad74`；
加 FP32 head 的原型提交为 `eab99fb76c5c0c451b04358d0068018ec23eca14`。
它们只存在于本地实验分支，逐序列 gather/分块计算并非可直接发布的生产实现。
前 14 步中 attention 原型降低了误差，但完整 64 步仍失败；不能只报告短前缀通过。

## 定位证据与边界

在原始候选的第 13、44、48 个预测位置，第一层 embedding、input norm、Q/K/V、
Q/K norm 和 RoPE 与 reference 的 BF16 值逐位一致；attention context 出现差异。
第 13 步的 context 有 413/2048 个分量不同，最大绝对差为 `0.001953125`，
后续层会放大差异。Prefill 和其他历史位置并非所有前置张量都完全相同，
因此不能据此断言 attention 是唯一来源。

作为反事实隔离实验，把候选的第一层 attention context 输入 reference 后，
检查的步骤 0、1、7、13、44、48 的第一层输出逐位一致。这支持相同输入下
后续投影、归一化和 MLP 的一致性，不是替换正式 reference 或完整算子正确性证明。

独立尝试 FP64 attention、不同 RMS 实现、融合 softmax 或拆分 QKV GEMM，
均未使完整用例达到原预算。更高的中间精度不保证更接近这个固定 BF16 reference。
失败的实验没有纳入生产分支。

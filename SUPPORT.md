# Getting help

Start with the [documentation index](docs/README.md) and [version-specific usage](docs/getting-started.md). This source archive preserves a historical experiment; for current usage, use [v0.2.0](https://github.com/RedHeartSecretMan/vllm-oxide/releases/tag/v0.2.0).

Public questions, bugs and documentation corrections belong in [GitHub Issues](https://github.com/RedHeartSecretMan/vllm-oxide/issues). English and Chinese are both welcome. Search existing reports first, then include:

- Version or exact source commit, and whether you are using the historical archive or current `main`.
- A minimal command or Rust example, expected behavior and actual result.
- Model ID/revision, generation settings and relevant short logs.
- For inference problems: operating system, GPU, driver, CUDA Toolkit and enabled Cargo features.

CPU/documentation reports need no GPU details. Remove access tokens and sensitive prompts before posting. Do not attach model weights or raw evidence packages. There is no guaranteed response time or separate support service.

For contributions, see [CONTRIBUTING.md](CONTRIBUTING.md). For vulnerabilities, use the private channel in [SECURITY.md](SECURITY.md).

# Community standards

This project welcomes contributors and users with different backgrounds and
levels of experience. These standards apply to repository issues, pull requests
and review discussions.

## Work together

- Discuss code and evidence respectfully. Explain disagreements with a concrete
  example or reproducible result, and make space for corrections.
- Help new contributors find the relevant documentation and keep reviews focused
  on the change. English and Chinese are both welcome.
- Credit others' work and respect the project's license and upstream licenses.
- Keep private information, credentials and other people's personal data out of
  public discussions.

Harassment, discriminatory abuse, threats, personal attacks and spam are
incompatible with participation. Repository maintainers may moderate content or
limit participation using GitHub's moderation tools.

## Report a concern

For abuse or harassment, use GitHub's **Report content** / **Report abuse** tools
or the [GitHub Support reporting route](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Share the relevant links with GitHub Support; keep private details out of a
public issue. Available in-product reporting options depend on your account and
repository permissions.

For software vulnerabilities, use the project's separate private channel in
[SECURITY.md](SECURITY.md). For technical help, use [SUPPORT.md](SUPPORT.md).

These project standards complement the
[GitHub Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines).

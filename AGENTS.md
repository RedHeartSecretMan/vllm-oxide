# vllm-oxide — Agent Instructions

Project context and domain vocabulary: see `CONTEXT.md`.

## Communication Rules

- **Use Chinese (中文) when communicating with the user.** This includes asking for confirmation, requesting clarification, reporting status, or any other proactive interaction. Exception: technical identifiers (issue numbers, commit hashes, Rust types, CLI commands) remain in their original language.

## Workflow Conventions

- **Ticket implementation**: use `/implement <NN>` to execute a ready-for-agent issue. Each ticket runs in its own branch (`feat/t<NN>-<slug>`) to avoid conflicts.
- **GitHub operations**: use `gh` CLI for all issue/PR operations. The repo is `RedHeartSecretMan/vllm-oxide`.
- **Golden fixtures**: generated by `tools/golden-gen/` (Python, GPU-only). Keep generated output and full raw evidence local and outside git. Upload evidence assets only when the user explicitly requests that upload; preserve original source identities and verdicts.
- **CUDA feature gate**: production code requires `--features cuda`. CI tests run CPU-only (`cargo test` without `--features cuda`).
- **Documentation**: start at `docs/README.md` for user, contributor, architecture and validation entrypoints. Keep the English and Chinese README aligned.
- **Releases**: follow `docs/releases/README.md` for release preparation and metadata updates. Preserve published tags; use existing user authorization for the requested publication work.
